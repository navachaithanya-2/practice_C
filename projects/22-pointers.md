# Pointers

## Exercises

1. Write a C program to swap two numbers using pointers.
2. Write a C program to print the value and address of a variable using a pointer.
3. Write a C program to calculate the sum of two numbers using pointers.
4. Write a C program to calculate the sum of elements of an array using a pointer.
5. Write a C program for sorting using a pointer.
6. Write a C program to find the sum of two numbers using a pointer to function.
