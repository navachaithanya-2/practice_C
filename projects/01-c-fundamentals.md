# C Fundamentals

These exercises introduce program structure, input, output, and basic conditions.

## Exercises

1. Print `Hello, World!`.
2. Read an integer and determine whether it is positive, negative, or zero.
3. Read an integer and determine whether it is even or odd.

## Concepts practiced

`main`, `printf`, `scanf`, variables, comparison operators, and the remainder operator.
