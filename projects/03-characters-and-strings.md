# Characters and Strings

## Exercises

1. Read and print a character using `getchar()` and `putchar()`.
2. Read and print a string using `fgets()` and `puts()`.
3. Convert a lowercase character to uppercase using character operations.

## Concepts practiced

Characters, strings, standard input, and safe line input.
