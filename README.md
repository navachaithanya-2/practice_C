# C Practice Problems for Beginners

A structured collection of beginner-friendly C programming exercises. Each project introduces one core concept, explains the approach, and provides a complete C solution.

## How to use this repository

1. Read the problem statement.
2. Try to solve it yourself.
3. Open the linked project page for the explanation and solution.

## Suggested conventions

- Use standard C (`C11`) and include input validation where appropriate.
- Keep each solution in its own `.c` file.
- Use meaningful variable and function names.
- Explain the algorithm before showing the code.
